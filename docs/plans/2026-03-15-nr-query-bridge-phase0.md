### Key constraint: nrqlEncoding.js

`nrqlEncoding.js` is imported by three files in shared-component:
- `shared-component/helpers/spl.js` (moves to package)
- `shared-component/helpers/lucene.ts` (stays — needs re-export)
- `shared-component/helpers/parsing.js` (stays — needs re-export)

The re-export at the original path ensures lucene.ts and parsing.js keep working.

### Jest configuration

The root jest config is auto-generated by NR1 CLI. Tests in `test/` are discovered automatically. The package needs its own jest config so `packages/nr-query-bridge/test/` tests run independently. The root config should also be able to discover them via `testPathPattern`.
